# SmartMind — ThanoSQL

> SmartMind AI Inc. is a South Korean AI company (Techstars 2020, Seoul) building
> ontology-based enterprise AI. Its current products are Qurify (natural-language data
> analysis combining structured databases and unstructured documents via a TAG+RAG, 2-tier
> ontology architecture) and AI-Minwon (a government/public-administration application).
> Its earlier product, ThanoSQL, is an analytical relational database with a built-in
> LLM/DL/ML query layer, exposed through a REST API and an official Python SDK. This profile
> captures the still-published ThanoSQL developer surface; the hosted ThanoSQL documentation
> has been decommissioned.

## APIs
- [ThanoSQL REST API (OpenAPI 3.0.2)](openapi/smartmind-thanosql-openapi.json): 34 operations over query, table, schema, view, table_template, file-manager, health, and metric resources. JWT Bearer auth (Authorization header). Base paths /api/v1 and /fm/api/v1 on a per-workspace engine URL.

## SDKs & Packages
- [thanosql (PyPI, official, MIT)](https://pypi.org/project/thanosql/): Python SDK, v1.0.11, Python >=3.8. `pip install thanosql`.
- [thanosql-magic (PyPI, official, archived)](https://pypi.org/project/thanosql-magic/): Jupyter/IPython SQL magic. `pip install 'thanosql[magic]'`.
- [SDK source](https://github.com/smartmind-team/thanosql-sdk-python)
- [SDK reference docs (live)](https://thanosql-sdk-python.readthedocs.io/en/latest/)
